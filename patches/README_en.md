# TensorFlow 2.15.0 Patch Release

This directory publishes the Kunpeng TensorFlow patches based on the fixed
official TensorFlow `v2.15.0` baseline:

```text
6887368d6d46223f460358323c4b76d61d1558a8
```

`SOURCE_COMMIT` records the development revision used for the release, and
`SHA256SUMS` records the artifact checksums.

## Maintained Patch Series

| Order | Group | Description |
| --- | --- | --- |
| 1 | `common` | Shared Bazel integration and general build fixes |
| 2 | `kdnn` | KDNN integration, KDNN kernels, and SparseMatmul optimization |
| 3 | `annc` | ANNC static graph fusion operators and tests |
| 4 | `kembedding` | KEmbedding custom operator, tests, and benchmarks |

The following build profiles are supported:

| Profile | Groups | Purpose |
| --- | --- | --- |
| `common-only` | common | Validate shared changes |
| `kdnn-core` | common + kdnn | Minimum recommended product profile |
| `kdnn-annc` | common + kdnn + annc | KDNN with ANNC |
| `full-default` | common + kdnn + annc + kembedding | Complete default profile |

Because `tensorflow/feature_copts.bzl` is generated for each feature set, use
`prepare_source.py` instead of manually applying the maintained patches:

```bash
git clone -b master https://gitcode.com/boostkit/tensorflow.git kunpeng-tensorflow
cd kunpeng-tensorflow
git remote add tensorflow-upstream https://github.com/tensorflow/tensorflow.git
git fetch tensorflow-upstream refs/tags/v2.15.0:refs/tags/v2.15.0

python3 patches/prepare_source.py \
  --feature-set kdnn-core \
  --output-dir ../tensorflow-kdnn-core
```

Change `--feature-set` to create another profile. KDNN profiles also require
the headers and libraries described in the KDNN installation documentation.

## Legacy Patch

`frozen_feature/tensorflow_2.15.0-legacy.patch` is a standalone, frozen
historical feature set.

The Legacy patch:

- Applies directly and only to the official TensorFlow `v2.15.0` baseline.
- Does not depend on `common` and is not the fifth step of the maintained series.
- Is not guaranteed to work with KDNN, ANNC, or KEmbedding patches.
- Does not accept new features and is not split into maintained subgroups.

```bash
git clone -b v2.15.0 https://github.com/tensorflow/tensorflow.git tensorflow-legacy
cd tensorflow-legacy
git apply --check ../kunpeng-tensorflow/patches/frozen_feature/tensorflow_2.15.0-legacy.patch
git apply ../kunpeng-tensorflow/patches/frozen_feature/tensorflow_2.15.0-legacy.patch

mkdir -p output distdir output-release
bazel --output_base="$PWD/output" build \
  --distdir="$PWD/distdir" \
  --config=fused_embedding \
  //tensorflow/tools/pip_package:build_pip_package
./bazel-bin/tensorflow/tools/pip_package/build_pip_package ./output-release
```

## Integrity Check

```bash
cd patches
sha256sum -c SHA256SUMS
```

`prepare_source.py` creates a complete source tree. `manifest.json` and
`patch_manager.py` maintain and verify the patch series. Files under `feature/`
are generated and must not be edited manually. The Legacy patch under `frozen_feature/`
is not regenerated by the patch manager.
